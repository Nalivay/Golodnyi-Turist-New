**Назначение:** Быстрое создание брендированных копий приложения для любого ресторана или ресторанной сети без разработки с нуля.

---

## 🌟 Как устроена система White-Label

Всё приложение централизовано. Вам **больше не нужно** искать названия и цвета по десяткам файлов.
Весь брендинг, логотипы, названия ресторанов, валюта и Telegram-каналы вынесены в **один файл конфигурации**:

📁 `src/config/whiteLabel.config.ts`

Когда вы меняете данные в этом файле, они **автоматически обновляются везде**:
- Экран приветствия (Splash Screen);
- Карточки выбора заведений;
- Бланки заказов кухни и поставщиков;
- Шапки бланков, печатные формы и Telegram-сообщения;
- Раздел технологических карт (Техкарты).

## 📋 Пошаговый алгоритм создания приложения для нового клиента

### ШАГ 1. Клонирование репозитория в Google AI Studio

1. **Экспорт репозитория:**
   - В верхнем правом углу Google AI Studio нажмите на меню проекта (три точки `⋮` или иконку GitHub).
   - Выберите **«Export to GitHub»** или сохраните ссылку на репозиторий.
2. **Создание нового проекта для клиента:**
   - На главной странице Google AI Studio Build нажмите **«New App»** -> **«Import from GitHub»** (или выберите «Clone»).
   - Укажите название нового проекта (например: `Заявки Кухни — Ресторан Монако`).
   - Нажмите **Create**. За 1-2 минуты у вас развернётся независимая рабочая копия со всей логикой, базой и голосовым вводом!

---

### ШАГ 2. Настройка брендинга в `src/config/whiteLabel.config.ts`

Откройте файл `src/config/whiteLabel.config.ts` и настройте параметры нового заведения:

```typescript
export const WHITE_LABEL_CONFIG: WhiteLabelConfig = {
  appBrand: {
    name: 'Ресторан «Монако»',                  // Название клиента
    subtitle: 'Электронный бланк заявок кухни', // Подзаголовок
    tagline: 'Система заявок',                   // Бейдж в шапке
    description: 'Быстрое голосовое и ручное формирование ежедневных заявок',
    footerText: 'Приложение «Монако» • Система снабжения',
    currencySymbol: '₽',                         // '₽', '$', '€', '₸', '฿'
    mainLogoType: 'custom',                      // 'armminsk' | 'custom' | 'monogram'
    customMainLogoUrl: '/monaco_logo.png',       // путь к файлу логотипа в public/
  },

  // 'single' — если у клиента 1 заведение (пропустит выбор и сразу откроет заказ)
  // 'multi' — если у клиента сеть (например, Ресторан + Бар + Кондитерская)
  mode: 'single', 
  defaultRestaurantId: 'monaco_main',

  restaurants: [
    {
      id: 'monaco_main',
      name: 'Ресторан «Монако»',
      shortName: 'Монако',
      indicator: '👑',                          // Эмодзи-маркер ресторана
      tagline: 'Создать заявку →',
      themeColor: '#D97706',                   // Фирменный цвет бренда (HEX)
      accentBorder: 'border-[#D97706]',
      badgeBg: 'bg-amber-100',
      badgeText: 'text-amber-800',
      logoType: 'custom',                      // 'custom' или 'monogram'
      customLogoUrl: '/monaco_banner.png',
      defaultTelegramGroup: 'Снабжение Монако',
    },
  ],

  support: {
    contactName: 'Андрей',
    telegram: '@Avakartsuk',
    email: 'Avakartsuk@gmail.com',
  },
};
```

### ШАГ 3. Добавление логотипа клиента

1. Положите файл логотипа в папку `/public` в корне проекта (например, `public/monaco_logo.png`).
2. В конфиге укажите: `customLogoUrl: '/monaco_logo.png'`.
3. **Если у клиента пока нет логотипа:**
   - Просто поставьте `logoType: 'monogram'`.
   - Приложение само сгенерирует стильный дизайнерский бейдж с инициалами заведения и фирменным цветом!

---

### ШАГ 4. Каталог продуктов и техкарты

Есть два удобных пути заполнения каталога:

#### Вариант А: Быстро прямо через интерфейс приложения (без кода)
- Откройте приложение и зайдите в режим заказа.
- Нажмите кнопку **➕ «Добавить продукт»** или **«Импорт из Excel»**.
- Товары сохранятся в базу автоматически.

#### Вариант Б: Задать начальный список в коде
- Отредактируйте файл `src/data/initialProducts.ts`, указав базовые позиции клиента (овощи, мясо, бакалея, хозтовары).
- Рецепты и техкарты можно добавить через `src/data/initialRecipes.ts` или прямо в приложении во вкладке **«📋 Техкарты»**.

### ШАГ 5. Настройка Telegram-уведомлений (для шеф-повара и директора)

Чтобы готовая заявка улетала в Telegram кухни в один клик:

1. **Создайте бота за 1 минуту:**
   - В Telegram откройте `@BotFather`.
   - Отправьте `/newbot`, задайте имя (например: `MonacoOrdersBot`).
   - Получите токен вида: `7123456789:AAH...`.
2. **Создайте группу в Telegram:**
   - Создайте группу «Заявки Кухни Монако».
   - Добавьте в неё вашего бота и сделайте администратором.
3. **Узнайте `Chat ID` группы:**
   - Добавьте в группу бота `@myidbot` или `@userinfobot` и отправьте `/getgroupid`.
   - Получите ID группы (обычно начинается с минуса, например: `-1001987654321`).
4. **Укажите в приложении:**
   - Нажмите иконку ⚙️ (Настройки) на экране выбора заведений и сохраните токен и Chat ID.

---

### ШАГ 6. Подключение облачной базы данных Firebase

У каждого клиента должна быть своя независимая база данных, чтобы заказы одного ресторана не попадали в другой:

1. В новом проекте AI Studio нажмите инструмент **Set up Firebase** (или в окне приложения нажмите **«Подключить базу»**).
2. База Firestore подключится автоматически.
3. Все смартфоны шефов, су-шефов и закупщиков этого ресторана мгновенно получат синхронизацию в реальном времени!

---

### ШАГ 7. Установка на телефоны персонала (PWA без App Store)

Приложению **не нужен App Store или Google Play**, что экономит вам месяцы модерации и 30% комиссии:

- **На iPhone (iOS):**
  1. Откройте ссылку на приложение в **Safari**.
  2. Нажмите кнопку «Поделиться» (квадрат со стрелочкой вверх).
  3. Выберите **«На экран Домой»** (Add to Home Screen).
  4. Приложение появится на рабочем столе как полноценная иконка и будет открываться на весь экран без рамок браузера!

- **На Android:**
  1. Откройте ссылку в **Google Chrome**.
  2. Нажмите всплывающую плашку внизу **«Установить приложение»** (или меню три точки -> «Установить на главный экран»).

## 💼 Коммерческий чек-лист перед продажей клиенту

Перед тем как передать ссылку клиенту и взять оплату:

- [ ] В `whiteLabel.config.ts` проверено правильное название и контакты заведения.
- [ ] Протестирован голосовой ввод: диктовка 3–4 позиций без повторного нажатия микрофона.
- [ ] Проверена отправка тестового заказа в Telegram-группу кухни.
- [ ] Загружены первые 30–50 основных позиций продуктов заведения.
- [ ] Проверено открытие технологических карт в разделе «Техкарты».
- [ ] Ссылка протестирована на смартфоне шеф-повара.

## 💰 Идеи монетизации для вас

1. **Разовое внедрение (Setup Fee):**
   - Настройка брендинга, забивка каталога продуктов из накладных клиента, настройка Telegram-бота и обучение шеф-повара.
2. **Ежемесячная подписка (SaaS):**
   - Абонентская плата за облачную базу, техподдержку и серверную синхронизацию.
3. **Комплекс «Сеть ресторанов»:**
   - Повышенный тариф для сетей от 2 заведений с общим складским сведением заявок в один сводный бланк для закупщика.
